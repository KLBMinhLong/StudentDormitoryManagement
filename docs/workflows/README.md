# Workflow Docs

Thư mục này gồm hai nhóm tài liệu:

- Workflow phát triển phần mềm.
- Workflow nghiệp vụ trọng yếu của hệ thống ký túc xá.

## Danh mục

- [development-workflow.md](development-workflow.md): Quy trình từ phân tích yêu cầu đến release.
- [business-workflows-overview.md](business-workflows-overview.md): Tổng quan các dòng chảy nghiệp vụ chính.
- [student-journey-workflow.md](student-journey-workflow.md): Hành trình nghiệp vụ của sinh viên.
- [contract-lifecycle-workflow.md](contract-lifecycle-workflow.md): Vòng đời hợp đồng nội trú.
- [utility-invoice-workflow.md](utility-invoice-workflow.md): Dòng chảy điện nước và hóa đơn.
- [payment-workflow.md](payment-workflow.md): Luồng thanh toán PayOS.

## Mục tiêu

- Đồng bộ cách làm việc khi phát triển tính năng mới.
- Tăng chất lượng review và giảm lỗi hồi quy.
- Chuẩn hóa hiểu biết nghiệp vụ end-to-end giữa BA, Dev, QA, vận hành.
