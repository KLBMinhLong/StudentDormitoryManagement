# Architecture Docs

Thư mục này mô tả kiến trúc hệ thống ở mức tổng quan và mức miền nghiệp vụ.

## Danh mục

- [system-overview.md](system-overview.md): Kiến trúc tổng thể, thành phần chính, luồng request.
- [domain-model.md](domain-model.md): Mô hình dữ liệu cốt lõi và quan hệ giữa các thực thể.
- [api-catalog.md](api-catalog.md): Danh mục endpoint API theo controller hiện tại.

## Mục tiêu

- Giúp thành viên mới nắm nhanh bức tranh hệ thống.
- Làm chuẩn tham chiếu khi mở rộng module mới.
- Giảm rủi ro sai lệch giữa backend, frontend và vận hành.
