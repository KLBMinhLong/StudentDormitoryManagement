## Cách đọc

Mỗi tài liệu gồm:

- Mục tiêu tính năng.
- Dòng chảy xử lý chính.
- Điều kiện nghiệp vụ.
- Vị trí code rõ ràng (file + class + method + line).
- Các tình huống lỗi và điểm kiểm soát.
