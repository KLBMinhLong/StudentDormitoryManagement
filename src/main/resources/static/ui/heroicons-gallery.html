6. Quick Usage Guidelines

  • ✓ Always use stroke-width="1.5" for outline icons
  • ✓ Use fill="none" for outline style
  • ✓ Default size is w-6 h-6 (24x24px)
  • ✓ Use currentColor to inherit text color
  • ✓ Apply color with Tailwind: text-primary, text-danger, etc.
  • ✓ Add animate-spin class for loading spinners
  • ✓ Include aria-label and title for accessibility

7. CDN Setup

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/heroicons@2.0.18/outline/index.min.css">

Add this link to the <head> section of your HTML files. No additional package installation needed!
